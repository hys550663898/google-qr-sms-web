⚡ Google 二维码降级短信助手（本地网页版）

与 Chrome 扩展版相同的原理，但不装扩展：本服务只运行在你本机，通过 Chrome 调试协议（CDP）给你的浏览器加上 iPad 环境伪装，并在二维码页内执行降级。

安全说明：本服务只监听 127.0.0.1，不收集、不上传任何数据；所有发往 Google 的请求都由你自己的 Chrome 发出。注意：带调试端口启动的 Chrome 可被本机任意程序控制，请使用独立的临时用户目录，用完后关闭这个 Chrome 窗口，不要用日常主力浏览器配置来开调试端口。

第 1 步：用调试端口启动一个 Chrome

先完全退出已打开的 Chrome，再用下面任一命令启动（独立用户目录，登录你的 Google 账号并走到二维码页）：

Windows

"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="%TEMP%\chrome-debug-qr"

macOS

/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug-qr

Linux

google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug-qr

第 2 步：选择标签页执行降级

推荐入口和扩展版一致：先在 Cloud Console 标签页点「唤起 Cloud Shell 验证」， 弹出二维码页后，回到这里对二维码页点「一键降级」。 如果你本来就卡在普通登录的二维码页，也可以直接对那个页面降级。 降级成功后伪装会保持到你点「释放伪装」或关闭标签页为止——请先完成短信验证再释放。
